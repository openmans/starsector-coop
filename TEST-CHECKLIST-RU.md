# Чек-лист ручной проверки Starsector Coop 0.2.25 (0.98.5a-RC9)

Живой прогон на двух (или 3–4) клиентах. Автотесты зелёные (4 700+ JUnit + sandbox/classloader);
здесь только то, что требует движка, графики и двух людей.

> Держите оба окна игры **видимыми**: свёрнутое окно Starsector не тикает кадры и через полминуты
> выглядит как обрыв связи. На странном моменте жмите **F11** — `COOP-MARK` ляжет в оба лога.
> Версия: `mods/coop/mod_info.json` = `0.2.25`, у друга **тот же zip** из релиза `v0.2.25`
> (хендшейк сверяет версию + git-хеш). Wingman для совместных боёв не нужен.

---

## 1. Установка и связь

- [ ] Оба ПК на 0.2.25 из одного релиза; `Coop Launcher.cmd` → Installation → все строки зелёные (в т.ч. `vmparams classpath integrity`).
- [ ] Порт 7777 доступен (LAN/VPN/проброс).
- [ ] Хост: Host a game → Copy invite; гость: Paste invite → Check connection (зелёный).
- [ ] Лобби: гость доходит до Ready, хост стартует, отсчёт, HUD `HOST/GUEST · session active`.
- [ ] Пауза гостем (`Space`) и перемотка (`Shift`) действуют у **обоих**.
- [ ] Обрыв у гостя (Alt+F4) → окно реконнекта → возврат в ту же сессию без потери мира.

## 2. Бой: живое пилотирование (live) — приоритет

Друг ввязывается в бой → у тебя окно выбора → **«Летать одним кораблём вместе с напарником»**.

- [ ] Ванильный **экран развёртывания не появляется** (раньше он и был багом: один корабль, 0 CP).
- [ ] Плашка: «Живой кооп-бой: вы пилотируете свой корабль. Очков командывания здесь нет…».
- [ ] Твой корабль на экране, камера на нём, **управление живое** (двигатели, оружие, щит).
- [ ] Видны корабли напарника и враги; попадания и смерти совпадают у обоих.
- [ ] После боя оба в кампании, потери записались в реальные флоты.

Ожидаемые строки: `Coop puppet arena: deployment dialog suppressed…`,
`Coop puppet arena initialised: removed N marker ship(s)…`, `Coop puppet arena: first streamed ship netId=…`.
Нет третьей строки — значит поток не идёт, шли лог.

## 3. Бой: Тактическая карта (командование своими кораблями)

Друг ввязывается в бой → **«Отправить флот и открыть Тактическую карту»**.

- [ ] Ты **остаёшься в кампании**, бой у тебя не начинается.
- [ ] Карта открылась сама (или Intel → Coop Session → Open Tactical Map).
- [ ] На карте твои корабли и враги, позиции обновляются (~5 Гц).
- [ ] Приказ (`ENGAGE`/`ESCORT`/`DEFEND`/`CAPTURE`/`WAYPOINT`/`RETREAT`/`CANCEL`) меняет поведение корабля у друга.
- [ ] **Пауза у друга** (Esc / свернулся на 1–2 минуты) не выбрасывает тебя из боя; после возврата карта снова живёт, общая пауза не снимается.

Строки: `Coop BATTLE_STATUS stream received…`; отказ приказа — `Coop BATTLE_ORDER rejected ship=… reason=…`.

## 4. Бой: ИИ-союзник, потери, обломки, делёж

- [ ] «Отправить флот как ИИ-союзника»: флот дерётся сам, ты в кампании, видишь баннеры начала/конца.
- [ ] Потери реальны: уничтоженные корабли исчезают из твоего флота; выжившие получают реальные hull%/CR.
- [ ] После боя приходит окно **Allied Wrecks**: восстановление тратит запасы, даёт четверть корпуса, 15% CR, 2 D-мода.
- [ ] `coop.lootSplit=equal`: за каждый поднятый обломок напарнику уходит половина стоимости корпуса (лента + кредиты); `pilot-keeps` — ничего.

## 5. Загрузка «за компанией» (`SESSION_LOAD`, новое)

- [ ] Хост загружает **другой** сейв кампании → у гостя **сам открывается экран загрузки** с подписью «Кооп: напарник загрузил кампанию …».
- [ ] В подписи назван его собственный сейв/персонаж; после загрузки сессия поднимается.
- [ ] Если у гостя нет сейва этой кампании — плашка «сейва этой кампании у вас нет», а не список чужих.

Строка: `Co-op load follow: campaign=… localSave=… character=…`.

## 6. Чат, обмен, опции

- [ ] **F8** (`coop.chatKey`) открывает чат; готовая фраза и свободный текст из поля доходят до напарника.
- [ ] Чат не лезет поверх реконнекта/десинка/лобби; в гостя-режиме клавиша не съедается блокировщиком ввода.
- [ ] **Trade with Partner**: Lock offer → правка после лока сбрасывает лок у партнёра → оба лока → Confirm → обмен атомарный; Cancel ничего не списывает.
- [ ] **Intel → Coop Options**: ни у одной опции нет пометки `no effect in this build`; `coop.partnerColor` применяется; `coop.feedVerbosity=minimal` оставляет только важное.

## 7. Кампания: колонии, баунти, сюжет

- [ ] Колонии: администратор-игрок / Alpha Core / персонаж синхронизируются; одновременное открытие экрана управления мягко блокируется у второго.
- [ ] `coop.incomeSplit`: `equal` (50/50) и `host-banks` (всё хосту) на конце месяца.
- [ ] Баунти: баунти хоста видны у гостя; гость убивает цель → `CREDITS_GRANT` и закрытие у обоих; своих системных баунти у гостя не спавнится.
- [ ] Сюжет (Galatia / Sindrian Diktat): флаги `$ga*`/`$sd*` доезжают до гостя без рассинхрона после сейва и перезахода.
- [ ] Хранилище > 1 МБ: большой склад открывается гостем целиком (`CoopMarketSnapshotChunker`).
- [ ] Гиперпространство: шторма (фазы совпадают), `Slipsurge`-прорезание, шлейфы Левиафана, призраки — только безопасные типы у гостя.

## 8. Шифрование (опционально)

- [ ] Одинаковые `coop.password` и `"coop.encryption":"aes-gcm"` → сессия работает.
- [ ] Клиент с `off` или другим паролем **не подключается** (отказ, а не «пустой мир»).

## 9. CGNAT-релей (только если нет проброса)

- [ ] На узле: `java -jar coop-launcher.jar --relay 7790`.
- [ ] У обоих: `"coop.relayAddress":"<адрес>:7790"`, одинаковые `"coop.relayRoom"` и `"coop.relayToken"`.
- [ ] Хост первым (регистрация), гость вторым → сессия поднимается; в логах `Coop host registered on relay` / `Coop guest joined relay`, состояние идёт по TCP-фолбэку.

## 10. Мульти-гость (3–4 игрока)

- [ ] `coop.maxGuests=2..3`, третий/четвёртый заходят, видны всем; гости в разных системах видят плавное движение NPC.
- [ ] Mid-session join (`coop.allowMidSessionJoin=true`) — второй гость заходит после старта.
- [ ] Один гость выпадает → его слот держится, **сессия не встаёт**, остальные играют; вернулся → resume принят. Истекло окно → его строка снимается, в ленте «did not come back».
- [ ] Выход одного гостя не ломает сессию остальным.

## 11. Если найдётся баг

1. В игре нажать **F11** (при желании с заметкой) — `COOP-MARK` в оба лога.
2. **Не перезапускать игру** до сбора логов.
3. Coop Launcher → **Logs → Save a bug report** (zip с `starsector.log`, `coop-launcher.log`, `[COOP-DOCTOR]`) на обоих ПК.
4. Написать: пункт чек-листа, кто хост/гость, что видел. Полезные греп-строки: `puppet arena`, `BATTLE_STATUS`, `BATTLE_ORDER`, `load follow`, `Coop net`.

## 12. Устарело — не тестировать

- **Wingman-бои** и всё из старого раздела «Fight Alongside»: в 0.2.24+ интеграция выключена, совместные бои — live / Тактическая карта / ИИ-союзник.
- **Headless dedicated server**: удалён в 0.2.24.
- `Ctrl+Shift+C` для чата (теперь **F8**) и `coop.encryption=true` (нужно `aes-gcm` **плюс** `coop.password`).
